# Custom GPT settings

Paste these into ChatGPT, Explore GPTs, Create, Configure.

**Name**: Global Talent Letter Helper

**Description**: Score, improve, polish or write letters of recommendation for the UK Global Talent visa (Tech Nation, digital technology), checked against the GOV.UK and Tech Nation rules.

**Instructions**: the whole of `instructions.md`.

**Conversation starters**:
- I'm a recommender. Here's my draft letter: score it and tell me what to improve.
- Polish my letter as tracked changes in Word.
- I'm the applicant. Help me plan my 3 letters from scratch.
- Write a fact pack for one of my referees.

**Knowledge**: upload every file in `knowledge/`.

**Capabilities**: turn on Code Interpreter & Data Analysis. Web Search is optional (useful for re-checking the GOV.UK and Tech Nation pages). Image generation and Canvas are not needed.

**Sharing**: "Anyone with the link" lets recommenders use it without searching for it. Free ChatGPT users can use a shared GPT, with usage limits.
